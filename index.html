Abstract

We propose LoopDVR, a framework for converting pretrained Transformer-based dense visual recognition models into parameter-efficient looped networks. Rather than reducing the network’s width or depth directly, LoopDVR shares Transformer blocks across selected layers in both the ViT backbone and query decoder, reducing the number of unique parameters while retaining the original computational structure. However, naively sharing parameters can disrupt the distinct representations and functions learned at different depths. To address this challenge, we use internal representations of the pretrained model to identify suitable sharing groups, initialize shared blocks using the pretrained weights of each group’s terminal layer, and introduce lightweight Loop Adapters to retain depth-specific transformations within shared blocks. We further distill visual representations into the looped backbone, integrate it with a looped query decoder, and train the resulting models for downstream dense recognition tasks. Experiments across four model scales demonstrate that LoopDVR achieves the best accuracy–parameter trade-offs in object detection, instance segmentation, and pose estimation with approximately 28% fewer parameters. Notably, LoopDet-S achieves 50.9 box AP with only 7.0M parameters, highlighting the effectiveness of parameter sharing in compact models.
